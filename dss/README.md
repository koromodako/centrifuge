# Centrifuge Plugin for Dataiku Science Studio (DSS)

This directory contains plugin code integrating Centrifuge capabilities into DSS flows.


## Setup

1. Create a zip archive named `centrifuge.zip` of `centrifuge/` directory
2. Go to `Plugins` then click `ADD PLUGIN` and select `Upload`
3. `Browse...` and select `centrifuge.zip`
4. Click `UPLOAD`
5. Follow the DSS instructions to complete the setup process


## Upgrade

Repeat Setup procedure and check `This is an update for an installed plugin` before step 4
